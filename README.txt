RU:
Инструкция:

1. Установите Python версии 3 и выше.
2. Установите Библиотеку keyboard (Откройте Командную строку и впишите "pip install keyboard" без скобок).
3. Установите Библиотеку tkinter (Откройте Командную строку и впишите "pip install tk" без скобок).
4. Запустите файл "Auto Key Presser.py".

5. Пользуйтесь.

------------

EN:
Instructions:

1. Install Python version 3 or higher.
2. Install the keyboard library (Open Command Prompt and type "pip install keyboard" without the parentheses).
3. Install the tkinter library (Open Command Prompt and type "pip install tk" without the parentheses).
4. Run the "Auto Key Presser.py" file.

5. Enjoy.
